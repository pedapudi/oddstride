# Oddstride

Oddstride is a robotics project for designing and building legged robots.

- [Tinfox](tinfox/README.md): a quadruped robot.
- [Longshanks](longshanks/README.md): a humanoid biped robot.

Tinfox has a [current CAD review and motor-fit assembly workflow](tinfox/README.md).
Each robot has its own directory for design notes, hardware, and software.
