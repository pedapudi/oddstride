# Compact shoulder proposal

This CAD proposal narrows the hip spacing and frame, and develops a controlled
precision-instrument exterior around the retained proximal knee transmission.

- [STEP assembly](model/output/tinfox-assembly.step)
- [Individual STEP archive](model/output/tinfox-individual-cad.zip)

The studio comparison pose is [0°, 45°, −75°]. The nominal standing pose remains
[0°, 30°, −60°]. Both are available in the viewer and checked separately.
The model remains an engineering prototype; loaded locomotion, print strength,
flexible gaiters, cabling and final interfaces require validation.
