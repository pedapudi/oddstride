# Historical Tinfox proposals

The compact and panelled proposals are historical geometry studies. Use the
[current Tinfox overview](../README.md), [robot viewer](http://127.0.0.1:8770/viewer/)
and [motor-complex assembly guide](../design/motor-complex-fit.md) for ongoing work.
Earlier sampled clearance results apply only to their recorded geometry.

The [historical design index](../viewer/archive/index.html) preserves access to
the earlier reviews. Legacy HTML entry points now display archive notices.
Their original files and render iterations are preserved under `../archive/browser/`
with hashes and restore instructions. The original proposal README is also backed up there.

The [studio reference](sculpted/design/studio-reference.png) and proposal source
generators remain in place as migration references. They do not establish current
geometry or native Fusion authority. Generated model outputs and hashed CAD
snapshots remain available while the native comparison audits are completed.
